Each task covers a specific concept — from simple conditionals to arrays, loops, strings, and basic algorithms.

## 📘 How to Use

* Each task can be written as an individual `.cpp` file.
* Run and test using **any C++ IDE** (CLion, Code::Blocks, Dev-C++, or VS Code).
* Focus on clean code, comments, and modular design.

## ⚙️ Recommended Setup

* **Compiler:** GCC / MinGW
* **Language Standard:** C++17 or later
* **Editor:** VS Code / CLion / Code::Blocks
